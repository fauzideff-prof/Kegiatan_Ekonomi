Petunjuk Penggunaan Guru

  • Buka file media_interaktif_ips_kegiatan_ekonomi.html langsung di peramban web modern (Chrome, Edge, Firefox).
  • Aplikasi bekerja secara mandiri tanpa memerlukan server eksternal.
  • Data tersimpan lokal melalui localStorage per-perangkat. Untuk mengumpulkan nilai satu kelas, guru dapat meminta siswa mengklik **"Ekspor CSV"** atau memperlihatkan layar Panel Guru ini.

Petunjuk Penggunaan Peserta Didik

  • Isi Nama Lengkap dan Kelasmu di Beranda terlebih dahulu.
  • Pelajari Modul 1 sampai Modul 8 secara runtut.
  • Mainkan Game "Petualangan Ekonomi" untuk mengumpulkan poin.
  • Kerjakan Ujian Evaluasi Akhir dengan cermat.

Petunjuk Navigasi Aplikasi

1. Beranda: Tempat mengisi identitas dan melihat gambaran umum media.

2. Modul Materi: Terbagi menjadi 8 topik lengkap disertai contoh riil masyarakat Indonesia.

3. Aktivitas Interaktif: Latihan berbasis aksi langsung seperti menyeret kartu dan simulasi kasir.

4. Game Edukatif: Kumpulkan poin dengan menyelesaikan 6 tantangan pulau Nusantara.

5. Evaluasi & Refleksi: Pengukuran nilai hasil belajar dan refleksi pengalaman pribadi.
